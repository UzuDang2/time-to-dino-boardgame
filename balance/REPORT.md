## 실제 수행 방법과 한계

`node balance/simulate.cjs`로 재현합니다. 실행 가능한 **실제 engine.js의 E.act**만 호출하여 재료·손패·행동·가방·전투·공룡·지형 순환을 처리했습니다. 결과를 만들기 위해 재료·행동을 주입하거나 승리 상태를 직접 설정하지 않았습니다. 원본 실행 결과와 동작 기록은 [runs-v024.json](runs-v024.json), 실행 정책은 [simulate.cjs](simulate.cjs), 요약은 [summary-v024.csv](summary-v024.csv)입니다. JSON에는 엔진·지형·정책 SHA-256을 기록했습니다.

고정한 10개 시드에 같은 정책을 사용했습니다. 본 집계 전에 24001 시드로 봇의 설치 좌표·창고 접근·막힌 손패 처리를 점검했고, 수정한 정책으로 10개를 모두 재실행했습니다. 파일 해시와 카드 집계 보완 후에도 같은 시드 전체를 다시 실행했으며 유리한 시드만 고르지 않았습니다.

- 목표는 개인 승점보다 전원 탈출입니다. 보이는 재료 중 필요한 종류를 우선 채집하고, 캠프에서 공용 창고로 공유한 뒤 금속·부품을 제작합니다.
- 필드에서 식량을 먹고, 가방이 차거나 체력·포만감이 낮아지면 귀환합니다. 공용 발각 5 이상에서는 가진 흔적 지우기를 우선합니다. 끝난 사냥은 남은 HP와 자신의 체력에 따라 계속/중단합니다.
- 공개된 지도만 경로 계산에 사용하고 뽑을 지형·이벤트·행동 카드 순서를 미리 보지 않습니다. 비행기에는 검증된 퍼즐 해답을 사용하므로 **배치 실수·퍼즐 판단 지연은 없는 유리한 조건**입니다.
- 건물 업그레이드, 개인 승점 경쟁, 공헌 이벤트 교환, 조리·허브 조합, 정교한 전투 계획과 팀 역할 분담은 최적화하지 않았습니다. 불리한 선택도 가능한 단순 정책입니다. 따라서 **이 60%는 사람 숙련자의 승률이 아니며, 최적 전략의 성공률도 아닙니다.**
- 10회는 구조적 병목을 찾는 소규모 진단입니다. 실제 사람의 마우스 조작·자원 이동·상담 시간을 측정한 테스트가 아닙니다.

## 눈에 띄는 문제

### 1. 60칸 자체보다 반복 재료 운반이 길어집니다

강철 48칸은 4칸 조각 **12개**입니다. 엔진 1개·냉각장치 1개와 합쳐 최소 14번 부품 조합, 여기에 배터리 2개 수급이 필요합니다.

현재 최소 재료 합계는 **금속15·나뭇가지12·돌1·줄기2·물1 = 31개**입니다. 금속15개를 전부 돌로 만들면 **돌31·나뭇가지12·줄기2·물1 = 원재료46개**가 됩니다. 이는 음식·무기·건물·손실을 제외한 수량입니다. 조합은 행동 무료여도 카드 비용과 왕복 운반은 남습니다.

**제안:** 비행기 외형과 연결된60칸은 유지하되, 고정 동체16칸을 처음부터 채워 둡니다. 사용자가 채울44칸은 **강철32칸(8조각) + 현재 특수 부품12칸**으로 잡습니다. 4조각만큼 수집·제련·제작·운반 부담을 줄이면서 테트리스 퍼즐은 유지합니다. 고정 동체는 중립색, 공헌0점으로 표시합니다. 배치 불가능한 빈 구역이 생기지 않도록 기존 해답의 완전한4조각을 고정하는 방식으로 설계합니다.

### 2. 마지막 필수 부품 하나가 게임을 붙잡습니다

4판 모두 비행기 대부분을 완성하고도 마지막 2~3칸 때문에 출발하지 못했습니다. 냉각장치는 물, 배터리는 이벤트/2레벨 유적 경로에 의존합니다. 공룡으로 길이 끊어진 뒤 운반이 늦어질 수도 있습니다.

**제안:** 배터리에 캠프의 확정 조합 **금속2 + 줄기1 + 카드1, 행동 무료**를 추가합니다. 유적/이벤트에서는 기존처럼 얻어 재료비를 아낄 수 있습니다. 냉각용 물의 무작위 지연은 초기 지형 덱 앞6장에 시냇물 최소1장을 포함하는 규칙으로 완화합니다. 시작 공개 지형은 여전히 캠프 하나뿐입니다. 두 제안은 현재 미적용입니다.

### 3. 손패 교체를 위해 의미 없는 이동이 생깁니다

사용하지 않은 카드는 보존하고 네 장까지만 보충하므로, 필요한 탐험 카드가 없으면 캠프에서 턴을 마쳐도 같은 손패가 남을 수 있습니다. 봇은 손패 순환을 위해 **38회 출발**했고 돌아오는 이동도 소모했습니다. 이는 봇 정책의 선택 횟수이며 사람도 반드시 같은 횟수를 해야 한다는 뜻은 아닙니다.

**제안:** 자기 턴 종료에 **손패1장을 무료 교체**하도록 합니다. 자원 생성·발각 감소 효과는 주지 않습니다. 무제한 새로 뽑기가 아니고 턴 종료 시 한 번만 허용하므로, 전용 흔적 지우기를 꾸준히 써야 하는 방향을 유지합니다. 좌우 카드 사용/버리기와 별개로 종료 화면에 교체1장 선택을 표시합니다.

### 4. 이번 표본에서 구조 패널티는 주된 지연 요인이 아니었습니다

구조는 총2회였습니다. 이 표본을 근거로 구조 감점·음식 소모·공룡 발각을 추가 완화할 필요는 보이지 않습니다. 먼저 비행기 작업량과 마지막 부품 지연을 조정한 뒤 다시 봅니다. 단, 보수적인 귀환 정책이 구조를 줄인 영향이 있습니다.

## 숙련자 40~60분 계획 — 아직 제안

시간 환산 가정은 **개인 턴35~40초 + 준비·공동 배치 확인8~12분**입니다. 실제 측정치가 아닙니다. 턴당 시간에 일반 토큰 조작·짧은 판단을 포함하고, 추가 시간은 세팅·공동 퍼즐 확인 등을 뜻합니다.

- 현재 성공판 평균83턴은 위 가정에서 약 **56~67분**입니다. 실패한120턴 판은 **78~92분**입니다. 현재 규칙으로 40~60분에 안정적으로 끝난다고 보기는 어렵습니다.
- 목표를 **14~18라운드 = 56~72개 개인 턴**으로 잡습니다. 같은 가정에서 약 **41~60분**입니다.
- 1차 후보: **고정 동체16칸 + 배터리 확정 조합 + 초기 시냇물 보장 + 종료 시 카드1장 교체**. 음식·개인/공용 발각·사냥 비용·구조 감점은 우선 유지합니다.
- 개선안이 14~18라운드에 수렴하는지 같은10개 시드와 추가 시드로 검증한 뒤, 40~60분 시나리오의 최종 제한을18라운드로 검토합니다. 지금 30라운드 제한만 먼저 줄이면 실패만 늘어날 수 있습니다.
- 실제 숙련자4인으로 최소3판을 진행해 **턴 판단/조작 시간, 마지막10칸 구간, 개인별 공헌·대기시간**을 기록합니다. 전체 플레이가60분을 넘으면 규칙 난이도와 UI 조작 시간을 구분해 조정합니다.
- 승인 후의 통과 목표: 자동 정책의 대다수가18라운드 안에 완료하고, 마지막 필수 부품만 기다리는 장기 정체가 줄어들며, 실제 숙련자3판이40~60분 범위에 들어오는지 확인합니다. 자동 플레이만으로 실플레이 시간 달성을 선언하지 않습니다.
