# 타임 투 다이노 — 플레이 가능한 보드게임 프로토타입 0.20

**플레이 주소:** https://uzudang2.github.io/time-to-dino-boardgame/

**저장소:** https://github.com/UzuDang2/time-to-dino-boardgame

기존 디지털 버전 `UzuDang2/time-to-dino`와 별개인 보드게임 프로토타입입니다. 설치 없이 PC·태블릿·휴대폰의 브라우저에서 열 수 있습니다. 인터넷이 연결된 환경에서 접속하며, 현재는 같은 기기에서 번갈아 하는 방식입니다. 온라인 동시 멀티플레이나 계정 간 자동 저장 동기화는 지원하지 않습니다.

원정은 기기·브라우저별로 자동 저장됩니다. 다른 기기에서 이어 하려면 **저장 파일**로 내려받은 뒤 새 기기에서 **불러오기**를 사용하세요. 기존 로컬 주소의 저장도 이 방식으로 가져옵니다.

배포는 GitHub Pages의 `main` 브랜치 `/ (root)`를 사용합니다. 업데이트는 변경·검수 후 `main`에 커밋하고 push하면 자동 반영됩니다. 별도 빌드나 패키지 설치는 필요 없습니다. `.nojekyll`로 정적 파일을 그대로 제공합니다.

대화에서 정한 육각 탐험·생존·사냥·거대 공룡 추격·캠프 건설 규칙을 실행 가능한 게임으로 구현했습니다. 0.3부터 자원을 주머니·타일·가방·지불 칸 사이에서 직접 옮깁니다.

0.16에서는 비행기를 하나로 연결된 60칸 도면으로 확장했습니다. 엔진 1개·배터리 2개·냉각 장치 1개·강철 48칸이 필요합니다. 강철은 I·O·T·L·S 중 고른 4칸 조각 1개로 제작하며 부위 경계를 넘어 설치할 수 있습니다.

완성품을 **가방 옆 임시 공간**에서 바로 받을 수 있습니다. 가방이 꽉 차도 조합할 수 있으며, 가방을 정리하거나 기존 물건을 현재 지형에 내려놓은 뒤 무료로 옮깁니다. 임시 완성품은 자동으로 지형에 떨어지지 않고 저장·불러오기 후에도 유지됩니다. 지형에 내려놓은 물건을 다시 가져오려면 채집 카드와 행동이 필요합니다. 완성품 배치를 마친 뒤 다음 행동을 합니다.

**조리·조합** 창에서 도구·장비를 자기 턴에 어디서든 조합할 수 있습니다. 돌창은 공방 없이 가지·돌·줄기 각 1개와 카드 1장·행동 1회로 조합합니다. 강철판·엔진·냉각 장치도 같은 창에서 제작할 수 있으며, 부족한 재료와 시설 조건을 표시합니다.

사냥은 **3장의 전투 카드를 해결하는 한 라운드마다 행동 1회**입니다. 라운드 뒤 한 번 더 싸우거나 그만두고 현재 칸에서 다른 행동을 할 수 있습니다. 남은 사냥감 체력은 보존합니다. 마지막 행동까지 사용하면 전투와 전리품 수령을 마친 뒤 자동으로 턴을 끝내며 포만감이 한 번 줄어듭니다.

카드 발동 → 피해 숫자·체력 감소 → 사냥감 반응을 차례로 보여주고, 처치하면 **사냥 성공·전리품 확인 화면**을 표시합니다. 수첩에서 **자원·전투 연출 켜짐/꺼짐**을 바꾸거나 재생 중 **Esc**로 넘길 수 있습니다. 운영체제 설정과 별도로 기본 켜짐이며, 건너뛰어도 확정한 비용·보상은 유지합니다.

기본 덱은 **12장: 탐험 4·채집 4·달리기 1·흔적 지우기 2·집중채집 1**입니다. 처음 4장을 뽑고 덱에 8장이 남습니다. **흔적 지우기**는 개인·공용 발각을 각각 1 낮추고, 현재 타일에 처음 인쇄된 종류의 자원 1개를 그 타일에 추가합니다. 모두 채집한 타일에서도 인쇄 정보를 기준으로 생성하며, 캠프처럼 인쇄 자원이 없는 곳에서는 발각만 낮춥니다.

필드에서도 굽기와 허브 조합을 할 수 있습니다. 완성 음식 1개마다 손패 1장을 쓰며 필드에서는 한 행동에 1개씩 만듭니다. 캠프의 굽기는 한 행동에 최대 2개, 주방 완성 후 3개까지이고 각각 카드가 필요합니다. 굽기의 연료는 한 번에 나뭇가지 1개입니다. 허브 조합은 카드 1장·행동 1회로 한 개씩 만들고, 분리는 무료입니다. 사냥 화면에는 몬스터별 고정 문자 패턴과 레벨 1·2의 A/B/C 행동을 모두 표시합니다.

**시작·캠프 출발 시에는 음식을 지급하지 않습니다.** 빈 가방으로 시작하고, 목적지를 고르면 수령 단계 없이 바로 이동합니다. 자동 채우기 버튼은 자원 배치 패널 안에 있으며, 자동 공급·수집은 토큰을 하나씩 옮겨 채운 뒤 완료한 패널이 아래로 닫힙니다.

0.10에서 추가한 지도 상단의 **공용 발각 12칸 보드**를 유지합니다. 개인 발각 8과 공용 발각 12 중 어느 한쪽이 한계에 닿으면 공룡 등장 조건을 만족합니다. 발각이 오르는 행동과 흔적 지우기는 개인·공용 수치를 각각 같은 양만큼 바꾸며, 개인 발각이 0이어도 공용 발각을 낮출 수 있습니다.

0.9에서는 **자동 채우기**로 새 타일의 자원을 한 번에 놓고, **자동 수집**으로 받을 물건이나 채집 자원을 가방 빈칸에 담을 수 있습니다. 가방의 기존 배치는 유지하고, 못 담은 채집 자원은 지형에 남기고 조합 완성품은 임시 공간에 유지합니다. 비상식량은 일자 2칸·포만감 +3이며, 비행기의 엔진은 2×2 전체에 그림 하나로 표시합니다.

캠프로 돌아오면 체력 8·포만감 6·개인 발각 0으로 초기화하고 즉시 턴을 마칩니다. 공용 발각은 유지됩니다. 다음 자기 턴에는 탐험을 떠나거나 자재 가공·건물 짓기·비행기 조립을 할 수 있습니다. 지도와 선택 지형의 큰 **캠프 둘러보기** 버튼으로 캠프를 엽니다.

나뭇가지 한 개는 가방 한 칸을 차지합니다. 가방 확장 건물은 가로로 긴 배낭 작업대 하나로 합쳤습니다. 왼쪽 LV1의 목재 8칸을 채우면 가방이 12→15칸, 오른쪽 LV2의 목재 4칸·섬유 4칸까지 채우면 21칸이 됩니다. LV2부터 조각을 놓을 수 있으며, 효과는 LV1부터 순서대로 적용합니다.

조합 완성품을 제외한 이벤트·전리품·보너스 등 가방에 들어가지 않는 획득물은 획득한 지형에 자동으로 남깁니다. 현재 가방 배치를 유지한 채 모든 회전·뒤집기를 확인하며, 일부를 받은 뒤 공간이 부족해진 나머지도 현장에 보존합니다. 남은 물품은 나중에 채집 카드로 가져올 수 있고, 캠프에 남겨진 물품도 같은 방식으로 회수합니다.

캠프 건설에는 돌출부와 빈칸이 있는 퍼즐 도면을 사용합니다. 카드 1장으로 고른 조각 1개를 만들며, 모양마다 필요한 재료가 다릅니다. 재료·모양별 조각은 모두가 공유하는 3개뿐이고, 도면의 보상 칸을 처음 덮으면 산딸기나 무료 조각을 받습니다.

공용 비행기를 함께 완성해 귀환하며, 음식은 앞뒷면을 뒤집어 굽거나 허브와 겹쳐 담습니다. 하단 가방은 기본 240px, 좁은 화면에서는 232px입니다. 일반 자원 주머니는 지도와 하단 패널 사이에 두 줄로 놓이고, 안쪽 가로 스크롤로 다른 종류를 볼 수 있습니다. 주머니는 처음 위치와 순서를 유지하며 필요한 주머니는 강조와 수량 배지만 표시합니다. 물품은 공용 타일 주머니에서 카드에 표시된 모양으로 꺼냅니다. 좁은 화면에서는 아래로 스크롤해 하단 패널에 접근하고 패널 안에서 가로로 이동합니다.

체력 또는 포만감이 0이면 **모든 아이템을 현재 지형에 남기고 캠프로 구조**됩니다. 개인 말판의 구조 컴포넌트에 횟수를 누적하며, **최종 점수 = 획득 승점 + 비행기 공헌 − 구조 횟수×2**입니다. 현재 승점이 0이어도 기록되고 회복으로 지워지지 않습니다. 무기·부품·겹친 음식은 원래 모양·내구도로 현장에 남으며 채집 카드로 회수합니다. 기존의 즉시 승점 감점과 허기 카드 추가는 사용하지 않습니다.

생고기는 **포만감 +1 · 체력 −1**, 구운 고기는 **포만감 +2 · 체력 +1**입니다. 허브 고기구이는 2층 보너스를 받아 포만감 +3·체력 +1이 됩니다. 구운 고기는 포만감이 가득해도 체력이 부족하면 먹을 수 있습니다.

## 바로 실행

- **가장 간단한 방법:** 이 폴더의 `index.html`을 Chrome/Edge/Safari 등 브라우저로 엽니다. 설치와 인터넷 연결이 필요 없습니다.
- **Mac 로컬 서버:** `Start.command`를 실행하면 브라우저가 열립니다. Python 3이 필요합니다. 터미널 창을 닫으면 로컬 서버가 종료됩니다.
- **터미널:** 이 폴더에서 `python3 server.py --open`을 실행합니다. 기본 주소는 `http://127.0.0.1:8767/`이며 사용 중이면 다음 빈 포트를 사용합니다.

게임은 한 PC에서 2~4명이 번갈아 조작합니다. 기본 설정은 4인 경쟁 원정입니다. 1인 선택은 조작·규칙 테스트를 위한 모드입니다.

## 첫 턴

1. 새 원정을 시작하면 기본 카드 12장을 섞고 4장을 손에 받는 과정을 볼 수 있습니다. 덱에는 8장이 남고 행동은 2회입니다. **시작 음식은 없으며 가방은 비어 있습니다.**
2. 처음 지도에는 **베이스캠프만** 공개됩니다. 탐험 카드를 아래 손패에서 위쪽 보드로 끌어놓고, 표시되는 행동 중 **탐험**을 고릅니다. 카드 클릭으로도 같은 선택을 할 수 있습니다.
3. 인접한 **＋칸**을 눌러 지형을 공개합니다. 타일에 적힌 종류와 수량만큼 공급 주머니에서 새 타일 또는 확대 트레이로 자원을 옮기거나 자원 배치 패널 안의 **자동 채우기**를 누른 뒤 **이 타일로 이동 / 현재 위치에 남기**를 고릅니다. 이동을 선택하면 즉시 새 타일로 갑니다. 탐험 후 선택 이동에는 추가 카드·행동이 들지 않습니다. 이벤트 지형에 도착하면 카드를 확인하고, 사냥감도 있으면 그 뒤 대치합니다.
4. 채집 카드로 행동을 고른 뒤 **타일 위 토큰이나 남겨진 물품을 가방으로** 하나씩 옮기거나 **자동 수집**을 누릅니다. 일반 채집은 최대 3개이며, 첫 물건을 담을 때만 카드 1장·행동 1회·발각 +1을 적용합니다. 물건을 담은 뒤 더 담을 수 없으면 나머지는 지형에 두고 자동으로 마칩니다. 처음부터 공간이 없으면 무료로 채집을 취소할 수 있습니다.
5. **턴 마치기**를 누르면 필드에서는 포만감이 1 줄고, 사용하지 않은 손패는 유지한 채 4장까지 보충합니다. 베이스캠프 안에서는 포만감이 줄지 않습니다. 처음 손패 구성도 섞인 결과에 따라 달라집니다.

첫 손패에 탐험 카드가 없으면 **흔적 지우기**로 카드를 사용하고 턴을 마쳐 새 카드를 받으세요. 임의 손패로 사용할 수 있으며, 개인 발각이 0이어도 손패를 순환하고 공용 발각을 낮출 수 있습니다. 캠프에서는 자원을 생성하지 않습니다.

가방에 칼이 있으면 **칼찌르기**, 돌창이 있으면 **창찌르기** 카드가 전투 화면에 나타납니다. 기본 손패 4장과 무기 카드를 합쳐 3장을 계획합니다. 두 무기는 각각 공격 2, 무기 한 개당 라운드에 한 번 사용하며 실제 해결한 무기만 내구도 1을 씁니다. 기본 공격에 자동 보너스를 붙이지 않습니다. 먼저 처치해 사용하지 않은 무기는 소모되지 않고, 파손·내려놓기·전달로 가방에서 빠지면 해당 카드도 없어집니다. 무기 카드는 기본 덱·버린 더미에 섞이지 않습니다.

공격 카드가 나오는 사냥 화면에서는 3장을 순서대로 고릅니다. 멧돼지의 기본 패턴은 **A → B → ?**, 노루·큰 거북은 **C → B → ?**입니다. **전투 시작 · 행동 1회**로 계획을 확정한 뒤 행동 카드를 뒤집어 첫 문자를 ?에 적용하고, **단계 진행**으로 내 카드와 해당 문자 행동을 차례로 해결합니다. 레벨에 따라 같은 문자의 효과가 달라집니다. 라운드 종료 후 행동이 남으면 **한 번 더 전투 / 그만 싸우기**를 선택합니다. 중단한 사냥감은 현재 위치의 **사냥하기**로 다시 싸울 수 있습니다. 마지막 행동으로 사냥감에게 도착했다면 다음 자기 턴에 전투를 시작합니다.

## 조작

| 대상 | 조작 |
|---|---|
| 지도 | 배경 드래그로 이동, 휠/± 버튼으로 확대·축소, ⌖로 내 위치 이동 |

캠프 팝업은 원래 탐험 지도가 있던 영역 안에 표시됩니다. 가공에 쓸 카드는 하단 실제 손패에서 고르며, 선택한 카드에는 강조 표시와 **1·2번 배지**가 붙습니다. 카드 한 장당 1~5칸 조각 하나를 선택하고, 두 장까지 **한 행동**에 가공합니다. 모양별 원재료 비용·공용 남은 수량·재료 충족 여부가 화면에 표시됩니다.

건설 자재는 **목재 5종·돌 5종·엮은 섬유 4종, 종류마다 공용 3개로 총 42개**입니다. 공통 한 칸은 원재료 2개, 두 칸 일자는 3개입니다. 목재 전용은 ㄴ자 3칸(가지 3)·Z형 4칸(4)·U형 5칸(3), 돌 전용은 긴 ㄴ자 4칸(돌 4)·S형 4칸(4)·정사각 4칸(5), 섬유 전용은 T형 4칸(줄기 4)·긴 지그재그 5칸(3)입니다. **회전만 가능하며 뒤집기는 불가**합니다. 보상 한 칸도 같은 3개 재고를 사용합니다. 자세한 표는 [RULES.md](RULES.md)에 있습니다.

드래그 대신 **출발 물건을 누른 뒤 목적지를 누르는 방식**도 가능합니다. 공급 주머니는 현재 받을 권리나 타일의 인쇄 수량만큼만 꺼낼 수 있습니다. 조리·조합의 지불이 끝나기 전 취소하면 올렸던 재료가 가방의 원래 자리로 돌아갑니다. 구운 음식은 생재료의 뒷면이므로 별도 공급 주머니를 표시하지 않습니다. 다만 이전 저장에 구운 음식 수령 대기가 남아 있으면 해당 주머니를 임시로 표시합니다.

시작과 캠프 출발의 산딸기 지급은 없습니다. 건설 칸의 산딸기 보상과 일반 채집은 그대로입니다.

자동 채우기·받을 물건 자동 수집·채집 자동 수집은 토큰이 약 **620ms** 동안 이동하며 여러 개일 때 **105ms 간격**으로 출발합니다. 도착할 때마다 실제 지도 토큰이나 가방 칸에 물건이 하나씩 나타나고, 모두 끝나면 완료한 패널이 아래로 닫힙니다.

직접 수령·채집·가방 정리, 재료 지불과 취소·소모, 음식 겹치기·분리, 반납, 비행기 납품과 건물 조각 배치도 실제 출발점과 도착점을 보여줍니다. 드래그로 옮겼다면 놓은 곳에서 짧게 착지합니다. 규칙 판정과 저장은 먼저 확정하며, 한 조작에서 재료 지불 후 소비까지 이어지면 연출도 순서대로 재생합니다. Esc로 넘겨도 확정한 행동이나 저장은 취소되지 않습니다.

허브 조합의 지불이 끝나면 바닥 음식과 허브가 차례로 같은 최종 가방 칸에 돌아오고, 허브가 도착한 뒤 2층 요리를 표시합니다. 흔적 지우기로 생긴 자원도 주머니에서 실제 지도 토큰 자리로 이동합니다. 건물·비행기는 조각이 도착한 뒤 채워진 모습을 공개합니다.

수첩의 **자원·전투 연출**은 운영체제의 **동작 줄이기**와 별개이며 기본 켜짐입니다. 끄면 자원 이동과 전투 연출을 생략합니다. 일반 패널·카드·미플 전환은 기기의 동작 줄이기 설정을 따릅니다. 같은 창에서 선택이나 수량만 바뀔 때는 창 전체를 다시 등장시키지 않습니다.

이벤트·사냥 전리품·건설 보너스 등 **조합 완성품을 제외한 물품**에는 같은 초과 처리 규칙을 적용합니다. 조합 완성품은 가방 옆 임시 공간에 유지하며 정리 후 무료로 받습니다. 가방 안의 기존 물건을 자동으로 재배치하지는 않습니다. 집중채집도 담을 수 없는 나머지를 지형에 남기고 끝나며, 아직 담을 수 있는 물건이 있으면 계속 채집합니다. 건설 조각은 기존처럼 건물·보관소에 배치하거나 공용 재고에 반납합니다.

## 승리와 저장

**공용 비행기의 60칸을 완성하고 전원이 베이스캠프로 돌아오면 출발할 수 있습니다.** 출발은 카드·행동을 쓰지 않습니다. 출발 시 **기존 승점 + 각자 납품한 부품의 공헌도**가 가장 높은 탐험가가 우승하고, 동점이면 공동 우승합니다. 개인별 6점 탈출 조건은 더 이상 사용하지 않습니다.

기본 작업대에서 강철·엔진·냉각 장치를 만들고, 배터리는 탐험으로 확보합니다. 부품 설치는 캠프에서 무료이며, 이미 놓은 부품은 고정됩니다. 구역별 모양·제작법·공헌 수치는 [RULES.md](RULES.md)에 정리했습니다. 수치는 첫 플레이 테스트용입니다.

매 조작이 현재 브라우저에 자동 저장됩니다. 다시 열면 이어서 할 수 있습니다. **저장 파일**로 JSON 파일을 내려받고 **불러오기**로 복원할 수 있습니다. 로컬 서버 주소와 `file://` 직접 실행은 서로 다른 저장 공간을 사용할 수 있으니 옮길 때 파일을 이용하세요.

타일 자원을 놓는 중, 채집 중, 재료를 지불하는 중뿐 아니라 이벤트 카드를 뒤집기 전·확인하기 전 상태도 저장합니다. 다시 열면 남은 단계부터 이어갑니다. 지형에 남긴 물품은 원래 물건의 식별자·내구도·겹친 재료·획득 위치를 유지합니다. 이전 저장의 일반 수령 대기도 보존하며, 가방에 들어가지 않는 물건은 원래 획득 지형에 남깁니다. 이벤트 보상을 다시 지급하지 않습니다.

이전 버전에서 시작 음식이나 출발 보급을 아직 받는 중이었다면 미수령 산딸기를 취소합니다. 이미 비용을 낸 출발은 예정된 목적지까지 추가 카드·행동 없이 이어집니다. 이미 가방에 받은 음식과 지형에 남긴 물건은 보존합니다. 다시 불러와도 이동이나 이벤트를 중복 처리하지 않습니다.

0.12 이전 저장은 흔적 지우기 카드가 두 장보다 적으면 덱에 한 장을 보충하고 전환을 기록합니다. 다시 불러와도 중복 보충하지 않으며 현재 손패·진행은 유지합니다. 옛 카드 1장으로 여러 음식을 준비한 미완료 조리는 재료·카드·행동을 보존한 채 취소하므로 음식 수에 맞게 카드를 다시 선택하세요.

0.13 이전 저장에서 이미 진행 중인 전투 라운드에는 행동 비용을 소급하지 않으며 다음 라운드부터 적용합니다. 행동 0으로 계획 중이던 사냥은 다음 자기 턴에 다시 대치합니다. 사냥 성공 화면·전리품 수령 대기도 저장하며 다시 열어도 승점과 전리품을 중복 지급하지 않습니다.

공용 발각은 개인 발각 합계와 별도로 저장합니다. 공용 수치가 없는 이전 저장을 처음 열 때만 개인 발각의 합을 최대 12로 제한해 초기값을 만들고, 이후에는 별도로 이어갑니다.

캠프 귀환·구조 시 HP 8·포만감 6·개인 발각 0으로 회복하는 효과는 해당 탐험가에게만 적용합니다. 공용 발각은 줄어들지 않고 그대로 유지됩니다.

0.1 저장 데이터는 원본 백업을 보존한 뒤 새 가방 구조로 변환합니다. 기존 물건을 새 모양으로 넣을 수 없으면 삭제하지 않고 수령 처리로 넘기며, 가방에 담을 수 없는 물건은 획득 지형에 남깁니다. 옛 저장에 획득 위치가 없으면 해당 탐험가의 현재 지형을 사용합니다. 기존 원정의 지도·손패·보유 물자는 유지되므로, 변경된 시작 과정을 보려면 **새 원정**을 시작하세요.

0.5의 새 퍼즐 도면은 아직 비어 있는 건물에만 적용합니다. 이미 조각을 놓았거나 완성한 건물의 도면과 배치는 유지합니다. 옛 저장에 공용 조각 재고가 없으면 보유 조각을 세어 남은 수량을 계산합니다. 이전 비용으로 진행 중이던 가공 지불은 재료·카드·행동을 보존한 채 취소하므로 새 비용을 확인해 다시 선택하세요.

0.7의 통합 작업대는 기존 가방 건물 세 개가 모두 미착수이고 확장 이력도 없을 때 전환합니다. 하나라도 착수·완성했거나 가방을 확장한 저장은 기존 가방 건물 세트와 진행을 통째로 보존합니다. 새 원정은 통합 작업대와 다른 건물 세 개로 시작합니다.

| 새 원정의 캠프 건물 | 요구 재료 칸 | 완성 효과 |
|---|---|---|
| 배낭 작업대 LV1·LV2 | 왼쪽 목재 8 / 오른쪽 목재 4 + 섬유 4 | 가방 12→15→21칸, 승점 1+2 |
| 야외 주방 | 목재 8 + 돌 4 | 조리 최대 3개 |
| 장비 공방 | 목재 8 + 섬유 8 | 완성 승점 2 · V3 조각·산딸기 보상 칸 |
| 자재 창고 | 목재 8 | 4×4 보관소 추가 |

상단 **↶**는 최근 35개 조작을 되돌립니다. 테스트용 편의 기능입니다. 이미 본 무작위 정보까지 잊게 하지는 않습니다.

## 구현 범위

- 35장 지형 원본 데이터를 반영한 육각 지도, 1/2레벨 선택, 타일 인쇄 자원과 흔적 지우기 추가 생성, 4색 미플.
- 탐험 손패 4장 / 2행동 / 위치별 이중 용도 카드 / 덱과 버린더미.
- 채집 3개, 개인 발각 8·공용 발각 12, 포만감·구조 횟수, 음식·조리·휴식·허브 치료, 캠프 귀환 자동 회복·턴 종료.
- 공급 주머니, 타일 인쇄 수량 채우기, 타일에서 가방으로 직접 채집, 재료 지불과 취소, 제작품 직접 수령.
- 가방 모양에 맞지 않는 획득물의 현장 보존, 일부 수령 뒤 남은 물품 자동 처리, 캠프를 포함한 재채집, 공간 부족 시 채집 자동 종료.
- 생재료 앞면/구운 음식 뒷면, 허브와 음식의 2층 겹치기, 포만감 보너스·무료 해체.
- 사용자 원본의 21칸 가방 외곽과 초기 잠금 9칸, 1칸 나뭇가지, 다칸 장비·부품, 직접 배치·회전·뒤집기·초과 처리와 내구도.
- 노루·멧돼지·큰 거북, 1/2레벨 카드, 3장 선계획, ABC 공개, 고유 능력, 공동 사냥 지원·전리품 분배.
- 티라노·스피노사우루스·알로사우루스, 추격 단계·대상 변경·접촉 피해·안전지대.
- 아이콘 조합표: 굽기·음식 겹치기·모양별 건설 자재·비행기 부품·돌창. 재료 수량, 결과물, 비용과 재료 충족 여부를 표시합니다. 조합표와 비행기는 시작 화면에서도 미리 볼 수 있습니다.
- 캠프 4개 퍼즐 도면, LV1·LV2 통합 배낭 작업대, 1~5칸 가공 조각, 재료·모양별 공용 3개 재고, 한 번만 받는 칸 보상, 가공·보상 공통 D 조각, 즉시 배치·반납, 기본 3×3 보관소와 건물 효과.
- 직접 뒤집고 확인하는 이벤트 덱·버린더미·퀘스트, 공용 타일 주머니, 배터리 조사, 승패, 자동 저장, 저장 파일, 되돌리기.
- 공용 비행기 5개 구역이 연결된 불규칙 60칸, 부품 제작·무료 납품, 공헌도 기록, 전원 귀환·최종 순위.

실물의 모든 물체를 자유롭게 던지는 물리 시뮬레이터 대신, 배치·이동·행동 비용을 게임이 판정하는 테이블 화면입니다. 네트워크 계정이나 외부 서버에 데이터를 보내지 않습니다. 수치 밸런스는 실제 4인 플레이를 거쳐 조정해야 합니다.

타일 자원은 채집하면 줄며 자동으로 재생되지 않습니다. **흔적 지우기 행동으로 첫 인쇄 자원 1개를 추가하는 예외**가 있습니다. 건설 조각은 재료·모양별 공용 3개로 제한합니다. 별도로 논의한 실물 구성품 총량 163개/183개를 일반 자원 주머니 전체의 재고 제한으로 적용한 상태는 아닙니다.

## 파일 구성과 검수

- `engine.js`: 화면과 분리한 규칙·상태 전이.
- `app.js`: 화면, 드래그·클릭, 저장/불러오기.
- `motion.js`, `motion.css`: 패널·카드·미플 전환, 시각 복제와 애니메이션 정리, 동작 줄이기 설정 반영.
- `resource-motion.js`, `manual-transfer-motion.js`, `resource-motion.css`: 자동·수동 자원 이동과 순차 연출, 수첩의 별도 켜짐/꺼짐 설정.
- `art.js`, `style.css`, `resource-table.css`, `bottom-dock.css`, `aircraft.css`, `event-deck.css`: 직접 작성한 SVG 그림·공급 주머니·하단 가방·비행기 보드·이벤트 카드와 캐주얼 테이블 디자인.
- `terrain-data.js`: 기존 지형 JSON에서 변환한 데이터. 덩이뿌리는 물/산딸기로 교체.
- `reference/camp-puzzle-design.json`: 현재 네 건물 52칸의 검증된 해답과 공용 재고 계산. 통합 작업대의 양쪽 독립 배치·경계 걸침 예시 포함.
- `tests.cjs`: 규칙 회귀 검사. `node --test tests.cjs`로 실행합니다.
- `server.py`, `Start.command`: 선택적으로 사용하는 로컬 실행기.

검수 결과는 [VERIFICATION.md](VERIFICATION.md)에 기록했습니다. 사용한 라이브러리를 다운로드하거나 패키지를 설치할 필요 없이 게임 자체는 HTML/CSS/JavaScript만으로 실행됩니다.
